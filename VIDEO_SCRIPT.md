# NanoOrCloud — demo video script (max 3:00)

Record at 1080p in a real Chrome browser (Prompt API flag enabled, Gemini
Nano downloaded), with the hosted app open. Show the Chrome version and
the on-device status. Speak in English, with English subtitles. Upload as
public on YouTube (Ngadi Ngadi Tech). Day 8 — Sat Nov 28.

| Time | Content |
| --- | --- |
| 0:00–0:20 | Problem: teams guess which AI tasks can stay on-device |
| 0:20–0:50 | Add tasks from presets in NanoOrCloud |
| 0:50–1:40 | Run side by side: on-device vs cloud, show outputs and latency |
| 1:40–2:15 | Report: routing recommendations and projected savings |
| 2:15–2:40 | How Firebase AI Logic hybrid and App Check are used (show code) |
| 2:40–3:00 | Value and close |

## Narration beats

- **0:00** — "Every team adding AI asks the same question: which tasks can
  run on a small on-device model, and which need the cloud? Guess wrong
  and you pay for it — in cost, in latency, in privacy."
- **0:20** — "NanoOrCloud answers it with data. I add my real task prompts —
  or load the five starter presets: summarize, classify, extract JSON,
  rewrite, Q&A."
- **0:50** — "One run. Every task goes to Gemini Nano on this device AND
  to Gemini in the cloud, side by side. Same prompt, both answers, latency
  and estimated cost in one table."
- **1:40** — "Then the report: per-task routing — on-device, escalate, or
  cloud — with confidence and a reason. And the savings: this is what the
  cloud bill looks like before and after routing."
- **2:15** — "Under the hood it's Firebase AI Logic hybrid inference:
  ONLY_ON_DEVICE and ONLY_IN_CLOUD, so there's no ambiguity about where
  each answer came from. App Check protects the cloud path."
- **2:40** — "Stop guessing when to use on-device AI. Try NanoOrCloud at
  the link below."
